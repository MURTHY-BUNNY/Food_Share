Account recovery

Reset your donor password

Enter the email address on your account. We send a 6-digit code to confirm the address, then you choose a new password.

  • The code expires 15 minutes after it is sent and only works once.
  • Another code can be requested 60 seconds after the last one.
  • Saving a new password signs out any browser still using the old one.
